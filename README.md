# 附近搜索与出行 Skill

按地点查询中国大陆附近的餐厅、类似蓝蛙的餐吧、万豪旅享家酒店和国铁客运站。可比较步行和驾车路线。

- **Codex（macOS）**：下载并解压 [安装包](https://github.com/1989roben-lab/travel/raw/refs/heads/main/nearby-travel.zip)，执行 `bash install-macos.sh`，再按提示配置自己的高德 Web 服务 Key 和大众点评会话。
- **Muse 网页版**：复制 [中文使用指令](nearby-travel/MUSE-PROMPT.txt) 到 Muse 聊天框，替换最后一行的地点和需求。
