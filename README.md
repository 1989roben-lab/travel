# hjh-travel：附近搜索与出行 Skill

按步行距离找最近的 10 家匹配餐厅并列出高德评分与人均，只列全市铁路火车站及各站打车距离和时间，并按打车距离找最近的 10 家万豪旅享家酒店。不搜索汽车站。

- **Codex（macOS）**：下载并解压 [安装包](https://github.com/1989roben-lab/travel/raw/refs/heads/main/hjh-travel.zip)，执行 `bash install-macos.sh`，然后按提示配置高德 Web 服务 Key。已安装 `nearby-travel` 的用户可用新版脚本迁移为 `hjh-travel`，高德 Key 和 MCP 配置沿用原位置。
- **Muse 网页版**：把 [完整 Skill 目录](https://github.com/1989roben-lab/travel/tree/main/hjh-travel) 发给 Muse，请它在云端工作区安装并验证。参见 [Muse 安装说明](hjh-travel/MUSE-INSTALL.md)。
