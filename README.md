# 附近搜索与出行 Skill

按步行距离找最近的 10 家匹配餐厅并列出大众点评综合评分，列出全市国铁客运站及各站打车距离和时间，并按打车距离找最近的 10 家万豪旅享家酒店。

- **Codex（macOS）**：下载并解压 [安装包](https://github.com/1989roben-lab/travel/raw/refs/heads/main/nearby-travel.zip)，执行 `bash install-macos.sh`，然后按提示配置高德 Web 服务 Key 和大众点评会话。已安装旧版的用户可重新运行新版安装脚本升级。
- **Muse 网页版**：把 [Skill 文件链接](https://github.com/1989roben-lab/travel/blob/main/nearby-travel/SKILL.md) 发给 Muse，请它在云端工作区安装并验证。参见 [Muse 安装说明](nearby-travel/MUSE-INSTALL.md)。
