# 附近搜索与出行

在中国大陆按实际步行距离找最近的 10 家匹配餐厅并列出高德评分与人均、按打车距离排前 10 的万豪旅享家酒店，或列出全市铁路火车站并逐站估算打车距离和时间。不搜索汽车站。

## 使用示例

| 场景 | 可以这样问 | 返回内容 |
|---|---|---|
| 找指定连锁 | 「上海静安寺附近，最近还营业的红盔甲是哪家？」 | 最近营业的分店、路线、高德评分。若更近的原分店已关门，会注明。 |
| 找相似餐厅 | 「杭州钱江世纪城附近，找类似蓝蛙的餐厅。」 | 默认按实际步行距离列最近的 10 家匹配餐厅，附步行时间、高德评分和人均。 |
| 找万豪酒店 | 「从杭州东站出发，查附近的万豪旅享家酒店。」 | 默认按打车距离列前 10，附地址、品牌、用时和官网。可指定只查 Marriott Hotels 主品牌。 |
| 查全市火车站 | 「以杭州奥体中心为起点，列出杭州市所有火车站。」 | 全市铁路火车站，含下辖区县，逐站给打车距离和预计用时。 |
| 一次查三类 | 「我要去杭州国际博览中心。帮我查全市火车站、附近万豪旅享家酒店和类似蓝蛙的餐厅。」 | 以同一个地点核对三份清单。 |

高德负责餐厅、评分、人均、地点和路线，万豪官网核对品牌。本包内置从 [12306 官网车站代码表](https://kyfw.12306.cn/otn/resources/js/framework/station_name.js)生成的全国索引（3413 站、431 个城市分组；生成时间见 `data/12306-stations.json`），可用 `python3 scripts/stations.py list --city 上海` 直接查名单，用 `python3 scripts/stations.py update` 刷新。代码表可能保留停办车站，城市分组也未必严格对应行政区；已核实城市名单在 `data/verified-cities.json`，其他城市遇到状态不明的站仍需核对。用户给出的数量、筛选条件和排序优先。无法核对的数据标为待确认。

## Codex（macOS）

1. 完整解压 ZIP。准备 Codex、Git（macOS 的 Xcode Command Line Tools 即可）及 Node.js 22.9 或更新版本。从解压后的目录在终端运行：

   ```bash
   bash install-macos.sh
   ```

2. 按脚本显示的命令打开本机 `.env`，在 `AMAP_API_KEY=` 后填自己的 [高德开放平台 Web 服务 Key](https://lbs.amap.com/)。保存后回到终端。
3. 重开 Codex，输入「用 `$nearby-travel`，以上海静安寺为起点，查全市火车站、最近的 10 家万豪旅享家酒店，以及类似蓝蛙的餐厅，按步行距离列最近的 10 家。」

安装脚本将固定版本的 [FoodNearBy-MCP](https://github.com/FunEnn/FoodNearBy-MCP) 下载到 Codex 用户目录的 `mcp-servers/nearby-travel/`，应用包内补丁，并注册 `nearby-amap`。补丁提供按地标搜索和路线查询。已安装且匹配时可重复运行。使用早期未修改版本的用户可用新版脚本升级 Skill。遇到同名但不兼容的配置时，脚本会显示冲突并退出。

如工具未出现，在终端运行 `codex mcp list`，检查服务是否启用，再打开一个新会话。高德报错时请检查 Key 的类型和状态；Skill 也会用可访问的高德网页继续查询。

## Muse 网页版

把完整的 `nearby-travel` 目录交给 [Muse](https://muse.ai/) 安装，以便一同提供本地铁路车站索引。详见 [Muse 网页版安装说明](MUSE-INSTALL.md)。

分享时发送原始 ZIP。每位用户在自己的机器上完成 Codex 配置。
