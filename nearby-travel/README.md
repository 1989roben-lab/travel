# 附近搜索与出行

在中国大陆按实际步行距离找最近的 10 家匹配餐厅并列出大众点评综合评分、按打车距离排前 10 的万豪旅享家酒店，或列出全市国铁客运站并逐站估算打车距离和时间。

## 使用示例

| 场景 | 可以这样问 | 返回内容 |
|---|---|---|
| 找指定连锁 | 「上海静安寺附近，最近还营业的红盔甲是哪家？」 | 最近营业的分店、路线、大众点评综合评分。若更近的原分店已关门，会注明。 |
| 找相似餐厅 | 「杭州钱江世纪城附近，找类似蓝蛙的餐厅。」 | 默认按实际步行距离列最近的 10 家匹配餐厅，附步行时间和大众点评综合评分。 |
| 找万豪酒店 | 「从杭州东站出发，查附近的万豪旅享家酒店。」 | 默认按打车距离列前 10，附地址、品牌、用时和官网。可指定只查 Marriott Hotels 主品牌。 |
| 查全市火车站 | 「以杭州奥体中心为起点，列出杭州市所有火车站。」 | 全市国铁客运站，含下辖区县，逐站给打车距离和预计用时。 |
| 一次查三类 | 「我要去杭州国际博览中心。帮我查全市火车站、附近万豪旅享家酒店和类似蓝蛙的餐厅。」 | 以同一个地点核对三份清单。 |

高德负责地点和路线，大众点评负责门店综合评分，万豪官网核对品牌，铁路和地方政府资料核对客运站。用户给出的数量、筛选条件和排序优先。无法核对的数据标为待确认。

## Codex（macOS）

1. 完整解压 ZIP。准备 Codex、Git（macOS 的 Xcode Command Line Tools 即可）、Node.js 22.9 或更新版本，以及 Chrome、Edge 或 Chromium。从解压后的目录在终端运行：

   ```bash
   bash install-macos.sh
   ```

2. 按脚本显示的命令打开本机 `.env`，在 `AMAP_API_KEY=` 后填自己的 [高德开放平台 Web 服务 Key](https://lbs.amap.com/)。保存后回到终端。
3. 运行脚本显示的登录命令，在独立浏览器窗口登录大众点评。若搜索页要求验证，在同一个浏览器窗口试搜一个餐厅关键词并完成验证。看到结果后回终端按 `Ctrl+C` 保存并释放会话，再重开 Codex。
4. 输入「用 `$nearby-travel`，以上海静安寺为起点，查全市火车站、最近的 10 家万豪旅享家酒店，以及类似蓝蛙的餐厅，按步行距离列最近的 10 家。」

安装脚本将固定版本的 [FoodNearBy-MCP](https://github.com/FunEnn/FoodNearBy-MCP) 和 [dp-mcp](https://github.com/qianwj/dp-mcp) 下载到 Codex 用户目录的 `mcp-servers/nearby-travel/`，应用包内补丁，并注册 `nearby-amap` 和 `nearby-dianping`。补丁提供按地标搜索和路线查询，并支持读取大众点评当前页面的综合评分及识别登录状态。已安装且匹配时可重复运行。使用早期未修改版本的用户可用新版脚本升级 Skill。遇到同名但不兼容的配置时，脚本会显示冲突并退出。点评浏览器会话沿用上游默认目录 `~/.dianping-mcp/browser-profile`。

如两个工具未出现，在终端运行 `codex mcp list`，检查服务是否启用，再打开一个新会话。若在点评登录窗口仍开着时调用点评工具，先关闭登录窗口。高德报错时请检查 Key 的类型和状态；Skill 也会用可访问的网页继续查询。
